# Video demos

Drop your demo clips in this folder (e.g. `rea-demo.mp4`, `supply-chain-demo.mp4`, `tcs-robot-demo.mp4`)
and reference them in the `<video>` tags inside `index.html`'s `#videos` section — the markup is already
commented in as an example next to each placeholder card.

For anything longer than a minute or two, prefer uploading to YouTube (unlisted is fine) and embedding an
`<iframe>` instead of committing a large video file to the repo. GitHub Pages has no problem serving small
MP4s, but keep the repo light.

Recommended: export an MP4 (H.264) under ~20MB per clip, and add a poster image (`*-poster.jpg`) so the
video card doesn't show a blank frame before playback.
